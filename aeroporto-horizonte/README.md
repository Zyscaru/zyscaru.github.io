# Aeroporto Horizonte

Jogo de SQL intermediário: 18 missões operando um aeroporto, com JOIN, LEFT JOIN, GROUP BY e HAVING, subconsultas, EXISTS, WITH, CASE, datas, UPDATE, INSERT ... SELECT, DELETE e transações. Cada missão é testada em três dias de operação. O app funciona offline depois de aberto uma vez.

## Instalar no celular

- **Android (Chrome):** menu ⋮ → **Instalar app**.
- **iPhone (Safari):** **Compartilhar** → **Adicionar à Tela de Início**.

## Atualizar

Envie os arquivos novos e aumente o número em `aeroporto-v1` no `sw.js`, para os celulares baixarem a versão nova.
