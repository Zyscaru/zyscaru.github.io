# Ferrovia do Futuro

Jogo de JavaScript intermediário: você escreve o software da Central de uma rede de trens maglev. São 18 missões em 6 linhas: funções e arrays, objetos e métodos de array, classes e herança, pilotos, closures e erros, código assíncrono (Promises, async/await, Promise.all) e algoritmos (busca em largura e rotas). O código roda no próprio navegador e o app funciona offline depois de aberto uma vez.

## Instalar no celular

- **Android (Chrome):** menu ⋮ → **Instalar app**.
- **iPhone (Safari):** **Compartilhar** → **Adicionar à Tela de Início**.

## Atualizar

Envie os arquivos novos e mude `ferrovia-v1` para `ferrovia-v2` (e assim por diante) no `sw.js`.
