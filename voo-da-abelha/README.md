# Voo da Abelha

Jogo para aprender JavaScript do zero: você escreve o código que guia a abelha Zuzu pelo jardim, coletando pólen das flores e voltando à colmeia. São 19 fases em 6 mundos (sequência, repetição, funções, sensores com if, laços while e variáveis). O código roda no próprio navegador e o app funciona offline depois de aberto uma vez.

## Instalar no celular

- **Android (Chrome):** menu ⋮ → **Instalar app**.
- **iPhone (Safari):** **Compartilhar** → **Adicionar à Tela de Início**.

## Atualizar

Envie os arquivos novos e mude `voodaabelha-v1` para `voodaabelha-v2` (e assim por diante) no `sw.js`.
