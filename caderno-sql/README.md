# Caderno de SQL

Curso interativo de SQL do zero, em português: 10 módulos e 67 etapas, com dois bancos de exemplo (uma biblioteca e uma loja). As consultas rodam num SQLite dentro do navegador, e cada uma é corrigida no banco original e num banco com outros dados. O app funciona offline depois de aberto uma vez.

## Instalar no celular

- **Android (Chrome):** menu ⋮ → **Instalar app**.
- **iPhone (Safari):** **Compartilhar** → **Adicionar à Tela de Início**.

## Atualizar

Envie os arquivos novos e aumente o número em `cadernosql-v2` no `sw.js`, para os celulares baixarem a versão nova.
