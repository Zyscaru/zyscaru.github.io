# Código em Jogo

Plataforma para aprender **Python** e **Java** jogando. Esta é a página inicial (https://zyscaru.github.io/), que reúne as duas trilhas e mostra o progresso de cada app:

| Nível | Trilha Python | Trilha Java |
|---|---|---|
| Do zero (curso) | [Caderno de Python](https://zyscaru.github.io/caderno-python/) | [Caderno de Java](https://zyscaru.github.io/caderno-java/) |
| Iniciante | [Robô Py](https://zyscaru.github.io/robo-py/) | [Rover em Marte](https://zyscaru.github.io/rover-marte/) |
| Intermediário | [Expedição Abissal](https://zyscaru.github.io/expedicao-abissal/) | [Missão Europa](https://zyscaru.github.io/missao-europa/) |
| Avançado | [Protocolo Neon](https://zyscaru.github.io/protocolo-neon/) | [Forja Real](https://zyscaru.github.io/forja-real/) |

Como todos os apps ficam no mesmo endereço (zyscaru.github.io), esta página consegue ler o progresso salvo por cada um no navegador.
