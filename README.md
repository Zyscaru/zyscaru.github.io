# Código em Jogo

Plataforma para aprender **Python**, **Java** e **JavaScript** jogando. Esta é a página inicial (https://zyscaru.github.io/), que reúne as três trilhas e mostra o progresso de cada app:

| Nível | Trilha Python | Trilha Java | Trilha JavaScript |
|---|---|---|---|
| Do zero (curso) | [Caderno de Python](https://zyscaru.github.io/caderno-python/) | [Caderno de Java](https://zyscaru.github.io/caderno-java/) | [Caderno de JavaScript](https://zyscaru.github.io/caderno-javascript/) |
| Iniciante | [Robô Py](https://zyscaru.github.io/robo-py/) | [Rover em Marte](https://zyscaru.github.io/rover-marte/) | [Voo da Abelha](https://zyscaru.github.io/voo-da-abelha/) |
| Intermediário | [Expedição Abissal](https://zyscaru.github.io/expedicao-abissal/) | [Missão Europa](https://zyscaru.github.io/missao-europa/) | [Ferrovia do Futuro](https://zyscaru.github.io/ferrovia-do-futuro/) |
| Avançado | [Protocolo Neon](https://zyscaru.github.io/protocolo-neon/) | [Forja Real](https://zyscaru.github.io/forja-real/) | [Estação Kepler](https://zyscaru.github.io/estacao-kepler/) |

Como todos os apps ficam no mesmo endereço (zyscaru.github.io), esta página consegue ler o progresso salvo por cada um no navegador.
