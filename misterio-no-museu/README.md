# Mistério no Museu

Jogo de SQL para iniciantes: 18 missões em 6 capítulos para descobrir quem levou a Coroa de Esmeraldas, usando SELECT, WHERE, ORDER BY, LIKE, IN, NULL, COUNT, GROUP BY e uma subconsulta final. Cada missão é testada em três versões do caso. O app funciona offline depois de aberto uma vez.

## Instalar no celular

- **Android (Chrome):** menu ⋮ → **Instalar app**.
- **iPhone (Safari):** **Compartilhar** → **Adicionar à Tela de Início**.

## Atualizar

Envie os arquivos novos e aumente o número em `museu-v1` no `sw.js`, para os celulares baixarem a versão nova.
