# Caderno de JavaScript

Curso interativo de JavaScript do zero, em português: 10 módulos com lições, exercícios corrigidos na hora, desafios, revisões, dois projetos e uma colinha. O código roda direto no navegador, isolado num Web Worker, e o app funciona offline depois de aberto uma vez.

## Instalar no celular

- **Android (Chrome):** menu ⋮ → **Instalar app**.
- **iPhone (Safari):** **Compartilhar** → **Adicionar à Tela de Início**.

## Atualizar

Envie os arquivos novos e mude `cadernojs-v1` para `cadernojs-v2` (e assim por diante) no `sw.js`, para os celulares baixarem a versão nova.

## Observação

O `console.log` mostra objetos e arrays no mesmo formato do Node.js. O `prompt()` aparece como uma caixinha no console do caderno, e o tempo de `setTimeout` e Promises é simulado, então as esperas acontecem na hora.
