# Base Amazônia

Jogo de SQL avançado: 18 missões numa base de pesquisa, com funções de janela, CTE recursiva sobre a rede de rios, séries e lacunas, JSON, views, UPSERT, gatilhos, índices e uma rota de resgate. Cada missão é testada em três expedições, com a rede de rios montada de jeitos diferentes. O app funciona offline depois de aberto uma vez.

## Instalar no celular

- **Android (Chrome):** menu ⋮ → **Instalar app**.
- **iPhone (Safari):** **Compartilhar** → **Adicionar à Tela de Início**.

## Atualizar

Envie os arquivos novos e aumente o número em `amazonia-v1` no `sw.js`, para os celulares baixarem a versão nova.
