# Estação Kepler

Jogo de JavaScript avançado: você escreve o software de uma estação espacial e do drone de manutenção KP-7. São 18 missões em 6 setores: funções de ordem superior (pipe, memoização, debounce), iteradores e geradores, classes com campos privados, eventos e erros personalizados, assíncrono avançado (Promise.race, limite de concorrência, for await), Proxy, expressões regulares, cópia profunda, heap, Dijkstra e busca com estado. O código roda no próprio navegador e o app funciona offline depois de aberto uma vez.

## Instalar no celular

- **Android (Chrome):** menu ⋮ → **Instalar app**.
- **iPhone (Safari):** **Compartilhar** → **Adicionar à Tela de Início**.

## Atualizar

Envie os arquivos novos e mude `kepler-v1` para `kepler-v2` (e assim por diante) no `sw.js`.
